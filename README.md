# Loctech IT-Training-Enugu-AWS-PROJECT_OMA
FinalCapstoneProject
AWS SERVERLESS TO-DO APP.
AWS SERVICES: API GATEWAY, AWS LAMBDA, DYNAMODB, IAM, CLOUDWATCH, S3.
THE APPLICATION SHOULD ALLOW USERS TO:
- CREATE A TASK.
- VIEW ALL TASKS.
- VIEW A SPECIFIC TASK.
- UPDATE A TASK.
- DELETE A TASK.
- MARK A TASK AS COMPLETED.
STEP 1: CREATE DYNAMO DB TABLE
STEP 2: CREATE IAM ROLE
STEP 3: CREATE A LAMBDA FUNCTION
STEP 4:CREATE API GATEWAY
STEP 5: CREATE THE OTHER LAMBDA FUNCTIONS.
STEP 6: TEST THE API
STEP 7: BUILD THE FRONT-END(INDEX.HTML, STYLE.CSS, SCRIPT.JS) AND BE HOSTED IN AMAZON S3, N:B: THE JAVASCRIPT COMMUNICATES WITH API GATEWAY.
STEP 8: ADD CLOUD-WATCH MONITORING.
